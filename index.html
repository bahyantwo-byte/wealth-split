👆 Set Up Back Tap
Double-tap the back of your iPhone to instantly log spending — without opening the app.
1
Open the Shortcuts app
It's pre-installed on every iPhone. Search for "Shortcuts" if you can't find it.
2
Tap the + button → Add Action
Search for "Ask for Input" and select it. Set the type to Number and the prompt to "How much did you spend?"
3
Add a "URL" action
Add a URL action and paste this exactly:
wealthsplit://add?type=expense&amount=[Provided Input]
4
Add "Open URLs" action
This tells the shortcut to open Wealth Split with that URL when it runs.
5
Name it "Quick Spend" and save
Tap the ✕ to close and save the shortcut.
6
Go to Back Tap settings
Settings → Accessibility → Touch → Back Tap → Double Tap → select "Quick Spend"
